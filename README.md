# staffsync-workforce-scheduling
StaffSync is a workforce scheduling optimisation application built using Python and Streamlit.  The application helps businesses allocate staff efficiently by analysing shift requirements,  staff availability, and scheduling constraints.  The goal is to reduce manual scheduling effort and improve operational efficiency.

## Problem Statement
Many businesses still rely on manual spreadsheets to schedule employees across shifts.
This process is time-consuming and often leads to inefficient staff allocation.

StaffSync addresses this problem by providing a data-driven workforce scheduling tool
that allocates staff to shifts based on availability and operational constraints.

## Features

- Workforce scheduling optimisation
- Staff availability input
- Automated shift allocation
- Interactive dashboard using Streamlit
- Data-driven scheduling output

- ## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy

- ## How to Run the Application

1. Clone the repository

git clone https://github.com/Dhruvj0398/staffsync-workforce-scheduling.git

2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py

## Example Use Case

A retail business with multiple employees and varying shift requirements can input
staff availability and shift demand into StaffSync. The application generates an
optimised workforce schedule that ensures efficient allocation of employees.
